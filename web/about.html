About

lantern keeps local telemetry local.

lantern exists for the part of observability that usually happens before a pull request or an incident review. You instrument an app, point the OpenTelemetry SDK at localhost, and want the trace waterfall, the log stream, the service edges, and the repeated failure groups without standing up a collector stack or sending data to a hosted vendor.

The project packages that flow into one binary. The OTLP receiver listens on the standard developer ports, the SQLite store keeps the session portable, and the snapshot command turns a recent debugging window into a bundle you can replay on another machine.

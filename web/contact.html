Report product issues in the open, security issues in private.

Use the GitHub issue tracker for reproducible bugs, feature requests, and questions about how lantern behaves in local developer environments. Include your command line, config, and a trace or log sample whenever possible so the maintainers can reproduce the issue quickly.

If you are reporting a vulnerability, follow the process documented in the repository security policy instead of opening a public issue. That keeps the report private until a patch or mitigation is ready.

Privacy

lantern stores debugging data on the machine that runs it.

The default workflow receives telemetry over OTLP, writes it into a local SQLite database, and serves the UI from the same process. The project does not require a hosted backend to inspect traces, logs, query spans, or grouped failures during day-to-day debugging.

Snapshot bundles are explicit exports. Review them before sharing because they may contain request names, attribute values, stack traces, or log payloads copied from your application. The `lantern clear` command wipes the local store when you want to remove retained data from the current machine.

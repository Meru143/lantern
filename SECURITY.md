# Security policy

Please do not open public GitHub issues for security vulnerabilities.

Use GitHub private vulnerability reporting if it is enabled for the repository. If private reporting is unavailable, contact the repository owner through GitHub before publishing details. Include the affected version, reproduction steps, impact, and any suggested mitigation.

We will acknowledge a report as quickly as possible, validate the impact, and coordinate a fix before public disclosure. Once a patch is available, the release notes and `CHANGELOG.md` will describe the remediation and any required upgrade steps.
